One sentence, at most 200 characters, about the best meal I ever had — a 2am street cart in Jakarta, soto ayam in the rain. A judge model compares the entries two at a time and keeps the one that makes the meal feel most concrete, most personal and most worth remembering.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later. It writes the sentence to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`) and checks first that it is 1–200 characters. Verify the result with:

```sh
wc -m /output/entry.txt && cat /output/entry.txt
```
